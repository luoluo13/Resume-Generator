# 简历工坊 Resume Studio

一款在**本机运行**的可视化简历制作工具。左侧选章节，中间填内容，右侧实时预览 A4 效果，完成后可导出 PDF、PNG 和 Word 文档。

所有数据都保存在本机项目目录中。不使用 AI 助手时全程离线；启用 AI 助手后，仅与你配置的模型服务通信，简历内容会随对话发送给该服务。

---

## 功能一览

### 内容编辑
- **基本信息**：姓名、求职意向、电话、邮箱、所在地、个人主页、照片
- **模块化章节**：教育背景、工作经历、项目经历、专业技能、荣誉奖项、证书、自定义模块
- 条目支持标题、补充信息、时间段、要点列表、技能标签
- 章节和条目均可新增、删除、调整顺序；章节支持拖动排序
- 要点支持加粗、斜体、链接三种格式，其余格式在导出时自动降级为纯文本

### 模板与样式
- **8 套内置模板**，视觉风格完全不同：

  | 模板 | 特点 |
  | --- | --- |
  | 笺 · 单栏经典 | 单栏、信息密度适中，适合大多数岗位 |
  | 简 · 紧凑单页 | 高密度单栏，适合内容较多、需要压在一页内 |
  | 衡 · 双栏均衡 | 左窄右宽双栏，联系方式与技能靠左 |
  | 序 · 时间轴 | 左侧时间轴串联经历，适合经历连贯的求职者 |
  | 雅 · 衬线学术 | 衬线标题 + 双栏正文，适合科研、教育岗位 |
  | 白 · 极简留白 | 大字号姓名、大量留白，适合设计与产品岗位 |
  | 格 · 杂志网格 | 黑白分栏网格，适合互联网与创意岗位 |
  | 丹 · 朱印封面 | 强调色标题压版面，视觉强烈但不失克制 |

- 每套模板自带多组**样式变体**，可在「主题设置」中切换
- 可调强调色（含自定义取色）、字体（思源黑体 / 思源宋体 / 微软雅黑）、字号、行距、页边距、单双栏、照片位置、分隔线样式、内容密度
- 切换模板只改变排版和配色，**不会修改任何文字内容**

### 导出
- **PDF**：文字可选中、可搜索，适合网申、邮件投递和打印
- **PNG**：3 倍分辨率高清图片，适合微信等即时通讯工具发送
- **DOCX**：可直接在 Word / WPS 中继续编辑，中文字体已做兼容处理
- 导出前自动重新渲染，保证与右侧预览一致
- 内容超过一页时会提示，并支持「一键紧凑」
- 导出文件默认保存在项目的 `exports/` 目录，可在导出面板中直接打开

### AI 助手
- 顶部「AI 助手」打开右侧对话面板，用自然语言直接修改简历
- 支持 **DeepSeek 官方 API** 与任意 **OpenAI 兼容的自定义供应商**
- 对话可以完成：基本信息修改、模块增删改、条目增删改与排序、切换模板、调整主题排版、导出 PDF / PNG / DOCX / JSON
- API Key 只保存在本机 `data/settings.json`，不会上传到其他服务
- 删除模块、删除条目会让对话先弹出确认卡片，确认后才执行，避免误删

### 模板中心
- 按单栏 / 双栏 / 衬线 / 自定义筛选模板
- **导入模板包**：支持 zip 格式自定义模板，导入前会做安全校验
- **下载模板开发包**：包含模板规范与示例，方便自行制作
- **复制 AI 提示词**：粘贴给任意 AI 生成模板包，再回到这里导入
- 自定义模板只允许 HTML / CSS，不执行任何脚本；PDF / PNG 与预览一致，DOCX 使用通用排版回退

### 数据安全
- 编辑内容自动保存，顶部显示「已保存 / 保存中 / 保存失败」
- AI 修改、JSON 导入前自动生成快照，`data/backups/` 最多保留 20 份
- 「数据」菜单支持导出 / 导入项目 JSON 备份，也可一键打开数据目录

## 快速开始

### 系统要求
- Windows 10 / 11
- 首次启动需要联网（依赖与 Chromium 内核优先使用国内镜像，失败自动回退官方源）
- 建议预留约 1GB 磁盘空间

### 启动步骤

1. 双击项目根目录下的 **`run.bat`**
2. 首次启动会自动完成：
   - 检查 Python 环境（缺失时安装到项目内 `.runtime\python`）
   - 创建虚拟环境 `.venv` 并安装依赖
   - 下载导出所需的 Chromium 内核
   - 启动本地服务并自动打开浏览器
3. 浏览器打开后即可开始编辑，地址通常是 `http://127.0.0.1:8765`（端口被占用时会自动顺延）

> 运行期间请不要关闭标题为「简历工坊 - 请勿关闭此窗口」的服务窗口。关闭它即停止服务，重新双击 `run.bat` 即可再次启动。

后续启动会跳过已完成的安装步骤，速度更快。

### 环境自检
- 导出失败时，关闭窗口后重新运行 `run.bat` 会自动补齐 Chromium 内核
- 「数据」菜单可以打开 `data/` 目录，查看简历数据与配置
- 中文字体缺失时会自动回退为微软雅黑

## 使用指南

### 1. 编辑内容

- 左侧列表选择「基本信息」或某个章节
- 中间表单填写内容，右侧预览实时更新
- 新增模块：左侧列表底部「添加模块」，选择模块类型即可
- 条目可用「上移 / 下移」调整顺序，要点可逐条增删
- 快捷键：`Ctrl + S` 立即保存，`Esc` 关闭当前弹层

### 2. 管理多份简历

- 顶部右侧显示当前简历名称，点击打开「简历库」
- 可新建、重命名、删除简历，也可以一键切换到其他简历继续编辑
- 每次修改都会自动保存，旧数据与历史快照都会保留，删除前请确认不再需要

### 3. 选择模板与调整样式

- 顶部「模板中心」可浏览全部模板，点击卡片即可切换
- 顶部「主题设置」调整颜色、字体、字号、行距、页边距、栏数、照片位置等
- 所有调整都会同步到预览和三种导出格式

### 4. 使用 AI 助手

1. 顶部点击「AI 助手」打开右侧面板
2. 首次使用选择供应商：
   - **DeepSeek 官方**：填写 API Key，选择 `deepseek-chat` 或 `deepseek-reasoner`
   - **自定义供应商**：填写 OpenAI 兼容的接口地址、模型名称与 API Key
3. 点击「测试连接」确认可用后保存
4. 在「操作简历」中选择本次要修改的简历，所有改动只会写入该简历；其他简历可以只读参考
5. 在「会话」中切换历史会话，或新建 / 删除会话，聊天记录会自动保存在本机
6. 直接输入需求，例如「新增一个项目经历」「把工作经历第二条改得更量化」「切换成双栏模板」「导出 PDF」
7. 删除模块或条目时，对话中会出现确认卡片，确认后才会执行
8. AI 回复为纯文本，不会出现 Markdown 格式符号

### 5. 导出

1. 顶部点击「导出」
2. 选择 PDF / PNG / DOCX，填写文件名（可留空自动命名）
3. 点击导出，完成后可直接打开所在文件夹

若提示内容超过一页，可点击「一键紧凑」压缩排版，或精简部分条目。

### 6. 备份与迁移

- 「数据」菜单 → 「导出 JSON 备份」，得到当前简历的完整数据文件
- 换电脑或重装时，通过「导入 JSON 数据」恢复
- 也可以在「数据」菜单中打开 `data/` 目录，手动复制 `data/resumes/` 下的简历文件

## 数据与目录说明

| 目录 / 文件 | 用途 |
| --- | --- |
| `run.bat` | 唯一启动入口，自动检查并补全运行环境 |
| `data/resumes/` | 多份简历数据，`index.json` 记录名称与当前简历 |
| `data/chats/` | AI 对话会话记录 |
| `data/backups/` | 历史快照，最多保留 20 份 |
| `data/assets/` | 上传的照片等资源 |
| `data/templates/` | 用户导入的自定义模板 |
| `exports/` | 导出的 PDF / PNG / DOCX 文件 |
| `templates/` | 内置模板 |
| `.runtime/` | 运行缓存、日志、浏览器内核、pip 缓存 |
| `.venv/` | Python 虚拟环境 |

运行环境、缓存和依赖都尽量放在项目目录内，不污染系统盘。

## 常见问题

**双击 run.bat 后浏览器打不开？**
请确认服务窗口仍在运行，也可手动访问 `http://127.0.0.1:8765`。

**导出 PDF / PNG 失败？**
多为 Chromium 内核缺失。关闭窗口后重新运行 `run.bat`，它会自动下载；网络受限时可稍后重试。

**AI 助手提示无法连接或 Key 无效？**
检查 API Key 是否正确、账户是否有余额；自定义供应商需要填写完整的 OpenAI 兼容地址（通常以 `/v1` 结尾）。可先点「测试连接」排查。

**AI 修改后内容不符合预期？**
可以在对话中继续说明要调整的地方；每次 AI 修改前都会自动生成快照，也可以在 `data/backups/` 中找回之前的数据。

**中文在 Word / WPS 里字体不对？**
导出时已同时设置中文字体与西文字体属性；若本机缺少对应字体，会自动回退到微软雅黑。

**内容太多，导出后不是一页？**
在导出面板点击「一键紧凑」，或删减条目、降低字号、缩小行距和页边距。

**想恢复之前的数据？**
在 `data/backups/` 中选择最近的快照，复制并覆盖 `data/resumes/` 下对应的简历文件，然后刷新页面。

## 开发者说明

普通用户无需关心本节。

- 技术栈：FastAPI + Pydantic v2（后端），React 18 + TypeScript + Vite（前端），生产环境由 FastAPI 直接托管 `frontend/dist`
- 修改前端源码后，在项目根目录运行 `build_frontend.bat`，或进入 `frontend` 执行 `npm install && npm run build`
- 内置模板位于 `templates/<id>/`，每套固定包含 `manifest.json`、`template.html`、`style.css`、`docx_builder.py`
- 模板包机制与安全校验见 `app/services/template_guard.py`；AI 对话与工具调用见 `app/services/chat.py`
