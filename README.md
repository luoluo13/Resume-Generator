# 简历工坊 Resume Studio

一款在**本机运行**的可视化简历制作工具。左侧选章节，中间填内容，右侧实时预览 A4 效果，完成后可导出 PDF、PNG 和 Word 文档。

所有数据都保存在本机项目目录中，不联网、不上传，适合投递、打印和长期维护。

---

## 功能一览

### 内容编辑
- **基本信息**：姓名、求职意向、电话、邮箱、所在地、个人主页、照片
- **模块化章节**：教育背景、工作经历、项目经历、专业技能、荣誉奖项、证书、自定义模块
- 条目支持标题、补充信息、时间段、要点列表、技能标签
- 章节和条目均可新增、删除、调整顺序；章节支持拖动排序
- 要点支持加粗、斜体、链接三种格式，其余格式在导出时自动降级为纯文本

### 模板与样式
- **8 套内置模板**，视觉风格完全不同：

  | 模板 | 特点 |
  | --- | --- |
  | 笺 · 单栏经典 | 单栏、信息密度适中，适合大多数岗位 |
  | 简 · 紧凑单页 | 高密度单栏，适合内容较多、需要压在一页内 |
  | 衡 · 双栏均衡 | 左窄右宽双栏，联系方式与技能靠左 |
  | 序 · 时间轴 | 左侧时间轴串联经历，适合经历连贯的求职者 |
  | 雅 · 衬线学术 | 衬线标题 + 双栏正文，适合科研、教育岗位 |
  | 白 · 极简留白 | 大字号姓名、大量留白，适合设计与产品岗位 |
  | 格 · 杂志网格 | 黑白分栏网格，适合互联网与创意岗位 |
  | 丹 · 朱印封面 | 强调色标题压版面，视觉强烈但不失克制 |

- 每套模板自带多组**样式变体**，可在「主题设置」中切换
- 可调强调色（含自定义取色）、字体（思源黑体 / 思源宋体 / 微软雅黑）、字号、行距、页边距、单双栏、照片位置、分隔线样式、内容密度
- 切换模板只改变排版和配色，**不会修改任何文字内容**

### 导出
- **PDF**：文字可选中、可搜索，适合网申、邮件投递和打印
- **PNG**：3 倍分辨率高清图片，适合微信等即时通讯工具发送
- **DOCX**：可直接在 Word / WPS 中继续编辑，中文字体已做兼容处理
- 导出前自动重新渲染，保证与右侧预览一致
- 内容超过一页时会提示，并支持「一键紧凑」
- 导出文件默认保存在项目的 `exports/` 目录，可在导出面板中直接打开

### 导入已有简历
支持把以前做好的简历导入后继续编辑：

- 支持 **DOC / DOCX / PDF**（单个文件不超过 12MB）
- 自动识别姓名、联系方式、教育、工作、项目、技能、荣誉等结构
- 四步校对向导：**上传文件 → 识别校对 → 样式选择 → 确认导入**
- 分析阶段不会修改现有数据；确认导入前会自动备份
- 只保证**内容完整保留并可编辑**，样式会按所选模板重新排版
- 旧版 `.doc` 需要本机安装 Word 或 LibreOffice 才能转换；扫描版 PDF 无文本层，无法识别

### 模板中心
- 按单栏 / 双栏 / 衬线 / 自定义筛选模板
- **导入模板包**：支持 zip 格式自定义模板，导入前会做安全校验
- **下载模板开发包**：包含模板规范与示例，方便自行制作
- **复制 AI 提示词**：粘贴给任意 AI 生成模板包，再回到这里导入
- 自定义模板只允许 HTML / CSS，不执行任何脚本；PDF / PNG 与预览一致，DOCX 使用通用排版回退

### 数据安全
- 编辑内容自动保存，顶部显示「已保存 / 保存中 / 保存失败」
- 每次导入、应用模板前自动生成快照，`data/backups/` 最多保留 20 份
- 「数据」菜单支持导出 / 导入 JSON 备份，也可一键打开数据目录

## 快速开始

### 系统要求
- Windows 10 / 11
- 首次启动需要联网（自动下载 Python 依赖与 Chromium 内核）
- 建议预留约 1GB 磁盘空间

### 启动步骤

1. 双击项目根目录下的 **`run.bat`**
2. 首次启动会自动完成：
   - 检查 Python 环境（缺失时安装到项目内 `.runtime\python`）
   - 创建虚拟环境 `.venv` 并安装依赖
   - 下载导出所需的 Chromium 内核
   - 启动本地服务并自动打开浏览器
3. 浏览器打开后即可开始编辑，地址通常是 `http://127.0.0.1:8765`（端口被占用时会自动顺延）

> 运行期间请不要关闭标题为「简历工坊 - 请勿关闭此窗口」的服务窗口。关闭它即停止服务，重新双击 `run.bat` 即可再次启动。

后续启动会跳过已完成的安装步骤，速度更快。

### 环境自检
顶部导航「运行环境」中可以查看：

- 服务地址、版本、Python 版本
- 数据 / 导出 / 日志目录，并可一键打开
- 中文字体与 Chromium 内核是否就绪
- 若导出内核缺失，关闭窗口后重新运行 `run.bat` 会自动补齐

## 使用指南

### 1. 编辑内容

- 左侧列表选择「基本信息」或某个章节
- 中间表单填写内容，右侧预览实时更新
- 新增模块：左侧列表底部「添加模块」，选择模块类型即可
- 条目可用「上移 / 下移」调整顺序，要点可逐条增删
- 快捷键：`Ctrl + S` 立即保存，`Esc` 关闭当前弹层

### 2. 选择模板与调整样式

- 顶部「模板中心」可浏览全部模板，点击卡片即可切换
- 顶部「主题设置」调整颜色、字体、字号、行距、页边距、栏数、照片位置等
- 所有调整都会同步到预览和三种导出格式

### 3. 导入已有简历

1. 顶部「数据」菜单 → 「导入已有简历（DOC / PDF）」
2. 上传文件后，检查识别出的姓名、联系方式、模块与条目
3. 可以修改标题、调整模块顺序、删除多余内容、补充遗漏条目
4. 选择一套模板，确认摘要后点击「导入并开始编辑」
5. 导入前的数据会自动备份，可随时通过 `data/backups/` 找回

### 4. 导出

1. 顶部点击「导出」
2. 选择 PDF / PNG / DOCX，填写文件名（可留空自动命名）
3. 点击导出，完成后可直接打开所在文件夹

若提示内容超过一页，可点击「一键紧凑」压缩排版，或精简部分条目。

### 5. 备份与迁移

- 「数据」菜单 → 「导出 JSON 备份」，得到完整的简历数据文件
- 换电脑或重装时，通过「导入 JSON」恢复
- 也可以在「运行环境」中打开 `data/` 目录，手动复制 `resume.json`

## 数据与目录说明

| 目录 / 文件 | 用途 |
| --- | --- |
| `run.bat` | 唯一启动入口，自动检查并补全运行环境 |
| `data/resume.json` | 当前简历数据 |
| `data/resume.json.bak` | 上一次保存的副本 |
| `data/backups/` | 历史快照，最多保留 20 份 |
| `data/assets/` | 上传的照片等资源 |
| `data/templates/` | 用户导入的自定义模板 |
| `exports/` | 导出的 PDF / PNG / DOCX 文件 |
| `templates/` | 内置模板 |
| `.runtime/` | 运行缓存、日志、浏览器内核、pip 缓存 |
| `.venv/` | Python 虚拟环境 |

运行环境、缓存和依赖都尽量放在项目目录内，不污染系统盘。

## 常见问题

**双击 run.bat 后浏览器打不开？**
请确认服务窗口仍在运行，并查看「运行环境」中的服务状态；也可手动访问 `http://127.0.0.1:8765`。

**导出 PDF / PNG 失败？**
多为 Chromium 内核缺失。关闭窗口后重新运行 `run.bat`，它会自动下载；网络受限时可稍后重试。

**导入 .doc 失败？**
旧版 `.doc` 需要本机安装 Microsoft Word 或 LibreOffice 才能转换。建议先用 Word / WPS 另存为 `.docx` 再导入。

**导入 PDF 后内容缺失？**
扫描件或图片型 PDF 没有文字层，无法解析（本工具不做 OCR）。请使用有文本层的 PDF，或改用 DOCX。

**中文在 Word / WPS 里字体不对？**
导出时已同时设置中文字体与西文字体属性；若本机缺少对应字体，会自动回退到微软雅黑。

**内容太多，导出后不是一页？**
在导出面板点击「一键紧凑」，或删减条目、降低字号、缩小行距和页边距。

**想恢复之前的数据？**
在 `data/backups/` 中选择最近的快照，复制并覆盖 `data/resume.json`，然后刷新页面。

## 开发者说明

普通用户无需关心本节。

- 技术栈：FastAPI + Pydantic v2（后端），React 18 + TypeScript + Vite（前端），生产环境由 FastAPI 直接托管 `frontend/dist`
- 修改前端源码后，在项目根目录运行 `build_frontend.bat`，或进入 `frontend` 执行 `npm install && npm run build`
- 内置模板位于 `templates/<id>/`，每套固定包含 `manifest.json`、`template.html`、`style.css`、`docx_builder.py`
- 模板包机制与安全校验见 `app/services/template_guard.py`；导入解析见 `app/importers/`
